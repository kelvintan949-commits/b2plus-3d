# B2+ Hotel Style 3D

Aplikasi 3D interaktif kamar kos B2+ (modul K.201, 3.50 × 5.00 m) — PWA yang bisa dipasang di smartphone dan PC.

**Buka:** https://kelvintan949-commits.github.io/b2plus-3d/

- Android / PC (Chrome, Edge): buka link, lalu tekan **Pasang**.
- iPhone / iPad (Safari): **Bagikan → Tambahkan ke Layar Utama**.
- Setelah dibuka sekali, aplikasi bisa dipakai tanpa internet.

Dibangun dengan three.js (MIT).
